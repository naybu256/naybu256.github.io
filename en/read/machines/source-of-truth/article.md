## The takeaway

A technical source of truth describes an interface’s current capabilities. A broader marketing page may describe services not fully exposed through that interface.

## The argument

While preparing this publication, TokPortal MCP documentation stated that YouTube bundle creation was unavailable through the API. Examples should retain that limit even when other pages mention YouTube more broadly. Cite dated documentation and check the schema before proposing a command.

When pages disagree, record their URLs, date and the scope of each statement. A tutorial may need correction even when the broader service has not changed. For executable examples, the capability of the specific endpoint is decisive. This prevents older marketing copy from becoming an invalid command and makes the limitation understandable without implying that every other interface has exactly the same scope.

## Choose which record wins before records disagree

A chat, spreadsheet, asset folder and publishing dashboard can each contain a slightly different campaign state. The problem becomes visible when two operators act on different versions of the truth. Assign a canonical record for the brief, approved asset, account identity and operation status. Link those records with durable identifiers instead of relying on filenames or memory. Keep changes timestamped and attributable. This does not require one enormous database; it requires a clear answer to which system owns each piece of information.

Define reconciliation rules for conflicts. A draft marked approved in a note does not override a later revocation in the review record. A local request marked sent does not override the platform's actual publication state. Preserve the evidence used to resolve the mismatch and expose uncertain states until they are checked. Avoid duplicating mutable facts across many documents when a reference would work. The editorial benefit is practical: people spend less time asking which version is current and more time deciding whether the current version is worth publishing.

### One owner for each kind of fact

- **Editorial:** The current brief and approved asset version.

- **Identity:** The account and destination identifiers.

- **Execution:** The operation receipt and reconciled state.

Editorial model: a way to reason about the process, not measured platform results.
